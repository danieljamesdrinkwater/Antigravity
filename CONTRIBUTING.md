# Contributing to Antigravity Plugins

We welcome contributions to the AGY performance ecosystem!

## Development Setup

1. Fork this repository.
2. Clone your fork locally.
3. Install the dependencies for the plugin you are modifying using `pip install -e .[dev]` inside the plugin's directory.
4. Run `pytest` before submitting a Pull Request.

## Coding Standards
- All Python code must be formatted using `black` and linted with `flake8`.
- Please ensure that type hints are used across all public APIs.
